# Day 17 — проверка (для видео)

## Подготовка

```bash
cd "day 17"
npm install
npm start
```

Открыть http://127.0.0.1:5016

## Сценарий

1. Нажать **Проверь статус подключения к M365** (или ввести тот же текст).
2. В треде: сообщение пользователя → ответ агента.
3. Под ответом блок **MCP tool call**:
   - `m365_connection_status({})`
   - `→` JSON со `status: "connected"` (+ displayName/mail) **или** `status: "not_connected"` + hint про login.
4. Текст агента опирается на этот JSON (не выдуман).

## Ожидание

Агент реально вызвал MCP `tools/call` и показал результат.
