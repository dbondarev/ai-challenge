# Day 13 — проверка multi-task FSM

## 1. Новая задача

1. http://127.0.0.1:5012
2. Вставь текст задачи (цель, бюджет, ограничения).
3. **Новая задача** → этап Planning, агент пересказывает и просит подтверждение.
4. Задача появляется справа.

## 2. Комментарий и переход

1. Комментарий: уточни scope → **Отправить комментарий**.
2. **→ Исполнение** — этап execution, агент говорит что делать дальше.
3. Пауза → спроси в комментарии «продолжай работу» — агент не должен двигаться.
4. **Продолжить** — продолжает без переспроса брифа.

## 3. Вторая задача

1. Создай другую задачу.
2. Переключись на первую в списке справа — диалог и этап те же, что были.
3. F5 — список и активная задача восстанавливаются из `tasks.json`.
